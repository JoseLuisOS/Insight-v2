# Guía de trabajo para Intersel Insight

Las reglas compartidas del repositorio (protocolo de lectura, modelo multi-organización, documentación) están en `AGENTS.md`, importado abajo.

- Para desarrollar sigue la skill `insight-dev`: la sesión principal razona y decide; los subagentes de `.claude/agents/` hacen búsquedas, implementación acotada, verificación, revisión y documentación.
- En este repositorio, el flujo de `insight-dev` prevalece sobre skills genéricas de proceso (p. ej. `superpowers:brainstorming`, `writing-plans`, `executing-plans`, `subagent-driven-development`). Úsalas solo si el usuario las pide explícitamente.
